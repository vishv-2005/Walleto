# CatMod: WhatsApp CRM Message Classifier Guide
--------------------------------------------------
This directory contains the core message classification system for your WhatsApp CRM. 
It uses a Hybrid Machine Learning + Rule-Based approach to handle Hinglish and noisy inputs.

### 1. FILE DESCRIPTIONS

- predict_cli.py: 
  Interactive Terminal Tool. This is the primary way to test the model in real-time. 
  It applies a high-priority "Rule Layer" BEFORE the ML model to ensure absolute precision 
  for Greetings (Namaste, Jai), Ordering verbs (Dedo, Bhejo), and Complaints.

- train_final.py: 
  Model Training Brain. Use this to retrain the system if you add new data. 
  It uses a LinearSVC model with "Hybrid N-Grams" (Word & Character) to understand 
  both the context and common Hinglish spelling variations.

- evaluate_testset.py: 
  Bulk Evaluation Script. Run this to test the model against a large CSV file (testset.csv). 
  It provides a detailed breakdown of how well the model handles real-world data.

- models/ [Folder]: 
  Model Storage. Contains 'categorizer_final.pkl', which is the trained brain of the system.

- requirements.txt: 
  Dependencies. Lists the Python libraries (pandas, scikit-learn, joblib) required to run the project.

- README.md: 
  Quick Start. High-level instructions for the project.

--------------------------------------------------
WHATSAPP CRM MESSAGE CLASSIFICATION SYSTEM
--------------------------------------------------

This directory contains the core message classification system for the WhatsApp CRM.

The system uses a Hybrid Approach:
- Machine Learning (TF-IDF + LinearSVC)
- Rule-Based Post-Processing

This combination enables the model to handle:
- Hinglish (Hindi + English mixed text)
- Informal WhatsApp messages
- Slang, abbreviations, and emojis

--------------------------------------------------
1. FILE DESCRIPTIONS
--------------------------------------------------

predict_cli.py:
Interactive Terminal Interface.
This script allows real-time message classification.

Key Features:
- Accepts user input from terminal
- Applies rule-based preprocessing layer BEFORE ML prediction
- Handles:
  - Greetings (e.g., "Namaste", "Jai Shree Krishna") → Irrelevant
  - Ordering phrases (e.g., "dedo", "bhejo") → Ordering
  - Complaint indicators (e.g., "bad", "late", "refund") → Complaint
- Outputs final predicted category

---

train_final.py:
Model Training Script.

Responsibilities:
- Loads training dataset
- Applies preprocessing (slang normalization, emoji handling, Hinglish mapping)
- Uses TF-IDF with:
  - Word n-grams (1–3)
  - Character n-grams (2–5)
- Trains LinearSVC model with balanced class weights
- Saves trained model to /models directory

---

evaluate_testset.py:
Evaluation Script.

Purpose:
- Evaluates model performance on real-world dataset (testset.csv)
- Ensures strict separation from training data (no leakage)
- Outputs:
  - Accuracy
  - Confusion Matrix
  - Precision, Recall, F1-score

---

models/:
Model Storage Directory.

Contains:
- categorizer_final.pkl → Final trained model used for prediction

---

requirements.txt:
Dependency List.

Includes:
- pandas
- scikit-learn
- joblib

Used for easy environment setup.

---

README.md:
Project Overview and Setup Guide.

Includes:
- Installation steps
- How to run training
- How to run evaluation
- How to use CLI tool
